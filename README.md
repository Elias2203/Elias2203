## 🚀 Featured Project

### 🍕 SectorPizza — Delivery Sector Processing System

A project focused on automating the processing of delivery tickets and assigning addresses to geographic sectors.

The goal is to transform operational information into structured data that can be processed, mapped, and analyzed.

**Key features:**

* 📄 Extract and process information from delivery ticket PDFs.
* 📍 Geolocate addresses and associate them with geographic sectors.
* 🗺️ Work with geographic data using GeoJSON.
* ⚡ Build a backend API to support the processing workflow.
* 📊 Prepare structured outputs for further analysis and reporting.
